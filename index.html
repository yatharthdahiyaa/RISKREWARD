Internal Salary Hike Model: Firth's Penalized GLM & Bootstrap

Evaluated on 137 verified junior analysts with B=2,000 resamples

Because the JDS cohort contains n = 137 observations, naive unregularized logistic regression risks quasi-complete separation. We apply Firth's penalized maximum likelihood and construct Bias-Corrected and Accelerated (BCa) bootstrap intervals:

Junior High-Hike Odds Multipliers per Standard Deviation:
  • Maths & Statistics: OR = 5.58x [95% BCa: 2.68, 21.62] — Ranks 1st in 65.2% of all 2,000 bootstrap draws!
  • AI & Machine Learning: OR = 3.65x [95% BCa: 1.33, 13.87] — Strong internal reward when foundational coding is present.
  • Storytelling & Dashboards: OR = 3.51x [95% BCa: 1.79, 17.46] — Critical differentiator for internal stakeholder visibility.
  • Big Data: OR = 2.73x [95% BCa: 1.52, 8.64] — Consistently positive across all bootstrap draws.
  • Core Coding: OR = 1.87x [95% BCa: 0.94, 4.72] — CI crosses parity (1.0)! Juniors are mostly at the ceiling (median = 5.0).

SAS Enterprise Production Pipeline (SAS Viya / CAS Engine)

PROC CASUTIL in-memory tables, PROC LOGISTIC cumulative logit, and Model Studio comparison

/*=============================================================================* * SAS ENTERPRISE PRODUCTION PIPELINE: TRI-AXIAL HUMAN CAPITAL DECISION ENGINE * * SAS CU Hackathon Round 2 & Round 3 Enterprise Implementation * * Platform: SAS Viya for Learners (VFL) / Cloud Analytic Services (CAS) * * Team: Aavishkar Hacks (Sachin Punetha, Yatharth Dahiya, Jayant Bana, Shivam) * *=============================================================================*/ /* 1. INITIALIZE CLOUD ANALYTIC SERVICES (CAS) SESSION */ cas casauto sessopts=(caslib="CASUSER" timeout=1800 locale="en_US"); libname casuser cas caslib="CASUSER"; /* 2. REGISTER IN-MEMORY CAS TABLES */ proc casutil; import datafile="/workspace/clean_data/clean_analytics_jobs.csv" outcaslib="CASUSER" casout="analytics_jobs" replace importoptions=(filetype="csv" getnames=True); import datafile="/workspace/clean_data/clean_jds_traits.csv" outcaslib="CASUSER" casout="jds_traits" replace importoptions=(filetype="csv" getnames=True); quit; /* 3. MODEL 1: PROPORTIONAL ODDS ORDINAL LOGISTIC REGRESSION (SALARY BANDS) */ proc logistic data=casuser.analytics_jobs outmodel=casuser.salary_model_fit plots(only)=(oddsratio effect); class exp_bracket(ref="0-2 yrs (Fresher/Entry)") metro_bengaluru(ref="0") / param=ref; model salary_ord = flag_big_data flag_maths_stats flag_core_coding flag_ai_ml flag_storytelling_dashboards exp_mid / link=clogit orpvalue; run; /* 4. MODEL 2: JUNIOR PROMOTION HIKE MODEL WITH FIRTH'S PENALTY */ proc logistic data=casuser.jds_traits plots(only)=(roc effect); model high_hike(event="1") = score_big_data score_maths_stats score_core_coding score_ai_ml score_storytelling_dashboards coding_x_storytelling / firth clodds=pl; run;
